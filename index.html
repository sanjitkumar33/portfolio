Zomato Clone Website

A responsive food delivery web application inspired by Zomato, built with React.js to showcase restaurant listings, menus, and online ordering features. The platform allows users to search and filter restaurants by cuisine, location, and ratings, and place orders seamlessly.

Key Features:

  • Search and filter restaurants by location, cuisine, and ratings.
  • View detailed restaurant pages with menus, prices, and reviews.
  • Add items to cart and manage orders.
  • Responsive design for mobile, tablet, and desktop.
  • Integrated with API for dynamic data rendering.

  • Frontend: React.js, HTML5, CSS3, JavaScript (ES6)

    PayUGuru – Online Payment Solution Aggregator

    PayUGuru is a modern online payment solution aggregator that enables businesses to accept and manage digital payments seamlessly. By integrating multiple payment services into a single platform, PayUGuru eliminates the complexity of working with different banks and payment providers individually.

    Our platform specializes in UPI-first payment solutions, offering a transparent, cost-effective, and developer-friendly way for merchants to collect payments anytime, anywhere.

    Key Features

  • UPI Integration – Supports UPI Intent, QR code payments, and dynamic UPI IDs.
  • Quick Onboarding – Simple registration and minimal documentation for fast setup.
  • Multiple Payment Partners – Ensures higher success rates and reduced downtime.
  • Secure Transactions – PCI-DSS compliance and RBI-aligned policies.
  • Custom APIs & Webhooks – Flexible integration for websites, apps, and POS systems.

    • Tech Stack

  • API Integration – REST APIs with sample code and documentation.
  • Hosted Checkout – Ready-to-use payment pages for quick launch.
  • QR Code Payment – Auto-generated dynamic QR for every transaction.
  • Webhooks – Real-time transaction status updates.
